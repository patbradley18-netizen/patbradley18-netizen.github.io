Cheat sheet — the whole language

say thingshow text in the Output pane. say "hello"
set name to valueremember a value. set score to 10
change name by nadd to a value. change score by 1 (same as set score to score + 1)
repeat n times … enddo the lines in between n times.
to name with inputs … endteach Ember a new action, then use it by name. to flower with x y … end, later: flower 100 120
give back valueinside an action: stop and hand a value to whoever called. to double with x / give back x * 2 / end — then say double 5
set name to a listone name, many things. add "Nero" to names · count of names · item 2 of names (items start at 1)
for each thing in list … enddo the lines once per item, in order. for each name in names … end
if test then … otherwise … endchoose between two paths.
is, is not, is greater than,
is less than, is at least, is at most		ways to compare. if score is at least 10 then
contains, does not containlook inside text, ignoring case. if reply contains "workforce" then — numbers and lists are searched by their written form.
+ − × ÷math with + - * / and ( ). + also joins text.
wait n secondspause, so drawings can animate. wait 0.5 seconds
random a to ba surprise whole number from a to b. set x to random 20 to 380
background colorpaint the whole canvas. background "midnightblue"
filled circle / filled boxsolid shapes. filled circle 200 200 40
when "key" pressed … endreact while the program runs. Keys: "left", "right", "up", "down", "space", letters. when "left" pressed … end
beepa short sound.
play notemusic! Notes 1–8 are a scale. play 1, or play 5 for 0.5 seconds
ask the web for "address" into namefetch a page's text (empty if no answer — sites also rot; write programs that expect silence). Works best in the terminal.
otherwise if test thenchain choices without nesting — any number of links, one shared end. if g is at least 90 then … otherwise if g is at least 80 then … otherwise … end
total of, highest of,
lowest of, average of		one number from a whole list. say total of scores (sum/biggest/smallest/mean are understood too)
words of, lines ofsplit text into a list. for each word in words of reply … end (blank lines are skipped)
put value into file "name"
add value to file "name"		keep things between runs: put replaces the file, add appends a line. Plain names only — files live beside the program (in the terminal) or in the page's pocket (press Files). put score into file "save.txt"
read file "name" into nameread a file's text back. A missing file reads as the empty text — programs should expect that. read file "save.txt" into memory
write text at x yput words on the canvas. write "score: " + score at 20 30
when clicked … endreact to a click or tap on the canvas. Inside, clickx and clicky hold the spot.
Learna built-in workshop: 14 small lessons, checked by Ember itself, from your first word to your own game. Lessons travel inside every gift.
Debugrun it out loud — every step narrated in plain words (· line 4 — stars = 5). Faults show themselves.
Stepthe debugger: one line at a time with Step / Continue / Stop — the current line named, every value visible as it changes.
■ Stophalt the running program where it is — a long animation or game stops cleanly between two statements, nothing half-done.
🎤 Speakdictate your program — Ember is made of sentences. Say "quote" for a quote mark, "end quote" to close it, "new line" to end a line. Needs a browser with speech recognition; everything else works without it.
shorthandfor tired hands, at the start of a line + Enter: rpt 5 → repeat 5 times, fe name in names → for each…, gb x → give back x, oi score is 5 → otherwise if … then, o → otherwise — and block openers bring their own end. The saved file is always full Ember; only your fingers get the discount.
